# Project2

## Описание:

Этот проект предоставляет ядро для интернет-магазина. В дальнейшем для этого ядра возможно будет реализовать любой
интерфейс — от сайта до телеграм-бота.

## Установка:

1. Убедись, что у тебя установлен Python версии 3.13.5

2. Клонируй репозиторий

```
git clone https://github.com/username/project-x.git
```

3. Установи зависимости

```
pip install -r requirements.txt
```
